# Analiza sprzedaży firmy XYZ
Jest to moj pierwszy projekt związany z analizą danych w Power Bi z użyciem SQL i bazy danych PostgreSQL.
---

## 🧰 Użyte technologie

- **Power BI** – wizualizacja danych, tworzenie dashboardu
- **PostgreSQL** – baza danych z przykładową strukturą sprzedaży
- **SQL** – zapytania do analizy danych
